## 1. 最终方案摘要

| # | 决策 | 结论 |
|---|---|---|
| 1 | 架构形态 | Java BFF（:8600）+ Python AI（:8700）+ 原生 Web |
| 2 | 对话框 | 单会话单输入框；SSE 流式；路由/任务/确认/事件统一事件模型 |
| 3 | Agent 接入 | 独立 Agent 层：Registry + Adapter SPI + CapabilityCatalog |
| 4 | 协议差异 | 物业 0.7 / 合同 0.6 方言由 Adapter 吸收；标准 Agent 走 Canonical v1 |
| 5 | 能力命名 | `capabilityId` 全局唯一，命名空间 `property.` / `contract.` |
| 6 | 凭据 | 只在 Java 侧；Python 不持有、不调用子 Agent |
| 7 | 确认 | 令牌存 Redis，浏览器只见 `taskNo`；绝不自动确认 |
| 8 | 数据 | 独立库/前缀/bucket；不直连子 Agent 存储 |
| 9 | 扩展 | 新增标准 Agent 零代码；方言 Agent 只加一个 Adapter |
| 10 | 自定义 Agent | 首期不做；P5 做受控模板，不做任意代码 |

## 3. Java 开发规范

### 3.1 分层

```text
Controller → Service → AgentGateway/Repository → Adapter/MyBatis
```

- Controller 只做参数校验、鉴权上下文、响应包装；
- Service 编排业务；
- Agent 层封装子 Agent 调用；
- Repository 只做持久化；
- 禁止 Controller 直接调用 Adapter/Mapper。

### 3.2 编码要求

- 遵循阿里巴巴 Java 开发手册；
- Java 21；构造器注入，禁止字段注入；
- DTO / VO / Entity 分离；禁止 Entity 直接出 Controller；
- 全局异常处理：`@RestControllerAdvice`；
- 参数校验：Jakarta Validation；
- 日志：SLF4J + 结构化字段；禁止 `System.out`；
- 敏感字段：日志脱敏（token/password/phone）；
- 核心逻辑中文注释，解释“为什么”而不是“是什么”；
- SQL 全部参数化；禁止字符串拼接；
- 时间统一 `Instant`/`OffsetDateTime`，DB 存 UTC。

### 3.3 Agent 层约束

- 所有子 Agent 调用必须经 `AgentAdapter`；
- 禁止在业务代码里直接 `RestTemplate/WebClient` 调子 Agent；
- Adapter 只做协议翻译，不做路由/业务判断；
- 新 Adapter 必须通过契约测试；
- 凭据只能从 `CredentialProvider` 取，禁止硬编码/打印。

---

## 4. Python 开发规范

- Python 3.13；`uv` 管理虚拟环境；
- FastAPI + Pydantic v2；异步 `httpx`；
- 禁止在 Python 侧保存子 Agent 凭据或调用子 Agent；
- LLM 输出必须经 Pydantic 校验；失败重试一次，仍失败回退规则；
- 提示词模板版本化（`prompts/`），变更需记录；
- `black` 格式化 + `ruff` 检查；
- 单测覆盖路由规则、槽位、JSON 解析失败、超时回退。

---

## 5. Web 开发规范

- 原生 HTML/CSS/JS（ES Modules），无构建步骤；
- SSE 用 `fetch` + `ReadableStream`，不用 `EventSource`（需要 POST）；
- Markdown 用本地 `marked` + `DOMPurify`，禁止 `innerHTML` 直接渲染模型输出；
- 所有 API 走统一 `api.js`，自动带 JWT、`traceId`；
- 错误提示可读，不暴露堆栈/内部地址；
- 确认卡片必须展示：操作、对象、关键字段、风险级别、过期时间；
- 移动端基础适配（单列布局）。

## 7. 数据库与迁移

- 使用 Flyway；生产禁止 `clean`；
- 迁移脚本只增不改；索引变更单独版本；
- 应用账号最小权限（仅 `wuye_agent_db`）；
- 所有查询带 `tenant_id` 预留；软删查询默认 `deleted_flag=0`；
- 大字段/JSON 不做模糊查询；必要时加生成列/索引。

## 8. 日志、异常与审计

### 8.1 日志字段

```text
timestamp, level, traceId, correlationId, sessionNo, taskNo,
agentKey, capabilityId, userId, action, status, latencyMs, errorCode
```

### 8.2 异常分层

| 异常 | 处理 |
|---|---|
| 参数校验 | 400 `VALIDATION_ERROR` |
| 鉴权/越权 | 401/403 |
| 子 Agent 4xx | 映射后返回，不重试 |
| 子 Agent 5xx/超时 | 重试一次（同 `clientTaskId`），仍失败 503 |
| LLM 超时 | 回退规则路由 |
| 未预期 | 500，记录堆栈，不回传细节 |

### 8.3 审计必记

- 登录成功/失败；
- 路由决策；
- 任务提交/确认/取消；
- Agent 注册/启停/Manifest 同步/能力开关；
- 附件上传/下载；
- 管理员查询审计。

## 9. 测试规范

### 9.1 分层

| 层 | 工具 | 覆盖 |
|---|---|---|
| 单元测试 | JUnit 5 / pytest | Adapter 映射、路由规则、槽位校验、错误码 |
| 契约测试 | WireMock / respx | Manifest、任务生命周期、确认、事件、鉴权负例 |
| 集成测试 | Spring Boot Test + Testcontainers（可选） | 会话、任务、确认、审计 |
| E2E | Playwright（可选）/ curl | 单对话框只读链路、确认链路 |
| 压测 | k6 / vegeta（可选） | 50 并发会话、路由 P95 |

### 9.2 Mock Agent

- 两个 Mock：`mock-property`、`mock-contract`，端口 `18402` / `18400`（测试专用，不登记为业务端口）；
- 按文档返回方言响应，用于 Adapter 契约测试；
- 支持故障注入：超时、500、429、SSE 断流。

### 9.3 必测用例

- [ ] Manifest 解析：物业 wrapped / 合同 raw；
- [ ] 状态归一化：6 种状态；
- [ ] 错误映射：401/403/404/409/429/503；
- [ ] 任务幂等：同键同体/异体；
- [ ] 确认：同意/拒绝/过期/重复；
- [ ] SSE：回放、增量、`done`、断线重连；
- [ ] 路由：明确/歧义/低置信度；
- [ ] 身份映射缺失 → 403；
- [ ] 子 Agent 停机 → 降级不 500。

## 12. 扩展新 Agent 的 SOP

1. 确认 Agent 符合 `06` 的 Canonical v1，或准备一个方言 Adapter；
2. 在 `wa_agent_registry` 注册（或管理 API）；
3. 在 `.env` 配置 `AGENT_<KEY>_*` 凭据；
4. 同步 Manifest，检查能力与版本；
5. 配置 `wa_identity_mapping`；
6. 跑契约测试 + 健康检查；
7. 灰度启用能力（先只读，再写）；
8. 观察指标与审计，确认无异常后全量。

## 15. 关键决策记录（ADR）

| ADR | 决策 | 理由 |
|---|---|---|
| ADR-001 | Java BFF + Python AI，Python 不调子 Agent | 凭据集中、审计集中；Python 只做推理 |
| ADR-002 | Agent 层独立，Registry + Adapter SPI | 扩展不改核心；方言隔离 |
| ADR-003 | 确认令牌只存服务端 | 防泄露；满足“绝不自动确认” |
| ADR-004 | `capabilityId` 命名空间 | 解决 `knowledge.search` 冲突 |
| ADR-005 | 首期逐个接入 + 声明式注册，不做自定义 Agent | 安全、可审计、可评测 |
| ADR-006 | SSE + 轮询降级 | 子 Agent SSE 可靠性不一 |
| ADR-007 | 不建物理外键 | 与既有项目一致；迁移灵活 |
| ADR-008 | 独立库/前缀/bucket | 符合共享中间件隔离要求 |
