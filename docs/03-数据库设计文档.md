# 03-数据库设计文档

> 项目：`wuye-agent`
> 版本：v0.1（设计稿）
> 日期：2026-11-20
> 数据库：MySQL 8.0
> 库名：`wuye_agent_db`（测试库 `wuye_agent_test_db`）
> 账号：`wuye_agent_app`（仅本库 DML/DDL，最小权限）
> 状态：DDL 待评审；建库/建账号需用户确认后执行

---

## 1. 设计约定

| 项 | 约定 |
|---|---|
| 引擎/字符集 | `InnoDB` / `utf8mb4` / `utf8mb4_0900_ai_ci` |
| 主键 | `id BIGINT UNSIGNED AUTO_INCREMENT` |
| 业务编号 | `*_no VARCHAR(32)`，如 `wt_20261120_0001`，全局唯一 |
| 时间 | `DATETIME(3)`；统一存 UTC，展示层转 `+08:00` |
| 软删除 | `deleted_flag TINYINT NOT NULL DEFAULT 0`；日志类表不软删 |
| 外键 | **不建物理外键**，用逻辑外键 + 索引（与 agent-gongdan 保持一致） |
| JSON | Manifest、Schema、事件 payload、审计摘要使用 `JSON` 列 |
| 敏感数据 | 密码 BCrypt；确认令牌不落库（Redis + TTL）；审计脱敏 |
| 多租户 | 所有业务表保留 `tenant_id VARCHAR(64) DEFAULT '0'`；首期单租户 |
| 迁移 | Flyway，禁止手工改生产库；脚本只增不改 |
| 命名 | 表前缀 `wa_`；字段 snake_case；索引 `idx_` / 唯一键 `uk_` |

```text
   │ N
   ▼

   │
   └── 1 ─── N wa_agent_manifest_snapshot

```

## 4. 表结构

> 下列各表默认包含公共字段：
> `id BIGINT UNSIGNED PK AUTO_INCREMENT`、`created_at DATETIME(3)`、`updated_at DATETIME(3)`、`deleted_flag TINYINT DEFAULT 0`（日志类表无 `deleted_flag`）。表中不再重复列出。

### 4.1 `wa_user`

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---:|---|---|
| `user_no` | VARCHAR(32) | 否 | - | 用户编号，唯一 |
| `username` | VARCHAR(64) | 否 | - | 登录名，唯一 |
| `password_hash` | VARCHAR(100) | 否 | - | BCrypt |
| `display_name` | VARCHAR(64) | 是 | NULL | 显示名 |
| `email` | VARCHAR(128) | 是 | NULL | 邮箱 |
| `phone` | VARCHAR(32) | 是 | NULL | 手机号（脱敏存储/展示） |
| `tenant_id` | VARCHAR(64) | 否 | '0' | 租户 |
| `status` | TINYINT | 否 | 1 | 1 启用 / 0 禁用 |
| `last_login_at` | DATETIME(3) | 是 | NULL | 最后登录 |

索引：`uk_user_no(user_no)`、`uk_username(username)`、`idx_tenant_status(tenant_id,status)`。

| 字段 | 类型 | 空 | 说明 |
|---|---|---:|---|
| `user_id` | BIGINT UNSIGNED | 否 | 主用户 |

| `scopes_json` | JSON | 是 | 允许的 scope |

关键 DDL：

```sql
CREATE TABLE wa_agent_registry (
  id                    BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  agent_key             VARCHAR(64)  NOT NULL COMMENT '子Agent唯一标识',
  display_name          VARCHAR(128) NOT NULL COMMENT '展示名',
  base_url              VARCHAR(512) NOT NULL COMMENT '子Agent基地址',
  protocol              VARCHAR(32)  NOT NULL DEFAULT 'agent-task-v1' COMMENT '协议',
  contract_version      VARCHAR(32)  DEFAULT NULL COMMENT 'Manifest版本',
  dialect               VARCHAR(32)  NOT NULL COMMENT '协议方言',
  envelope              VARCHAR(16)  NOT NULL DEFAULT 'raw' COMMENT '响应包络',
  auth_mode             VARCHAR(32)  NOT NULL COMMENT '鉴权模式',
  credential_ref        VARCHAR(128) NOT NULL COMMENT '凭据环境变量前缀',
  manifest_url          VARCHAR(512) DEFAULT NULL COMMENT 'Manifest地址',
  health_path           VARCHAR(128) DEFAULT NULL COMMENT '健康检查路径',
  ready_path            VARCHAR(128) DEFAULT NULL COMMENT '就绪检查路径',
  manifest_json         JSON         DEFAULT NULL COMMENT '最近Manifest快照',
  manifest_version      VARCHAR(32)  DEFAULT NULL COMMENT 'Manifest版本号',
  status                VARCHAR(16)  NOT NULL DEFAULT 'DISABLED' COMMENT 'ENABLED/DEGRADED/DISABLED',
  enabled               TINYINT      NOT NULL DEFAULT 0 COMMENT '是否启用',
  last_synced_at        DATETIME(3)  DEFAULT NULL COMMENT 'Manifest同步时间',
  last_health_at        DATETIME(3)  DEFAULT NULL COMMENT '最近探活时间',
  last_health_status    VARCHAR(16)  DEFAULT NULL COMMENT 'UP/DOWN',
  failure_count         INT          NOT NULL DEFAULT 0 COMMENT '连续失败次数',
  created_at            DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at            DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  deleted_flag          TINYINT      NOT NULL DEFAULT 0,
  PRIMARY KEY (id),
  UNIQUE KEY uk_agent_key (agent_key),
  KEY idx_status_enabled (status, enabled)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='子Agent注册表';
```

## 5. 关键设计说明

### 5.1 幂等

- 用户消息：`uk_session_client(session_id, client_message_id)`，重复提交返回原消息。
- 任务：`uk_agent_client_task(agent_key, client_task_id)`，重试必须复用 `clientTaskId`。
- 确认：任务状态机保证一次性；重复确认返回 `409 TASK_STATE_CONFLICT`。

### 5.2 事件序号

- `wa_task_event.seq` 在单任务内单调递增，由 `TaskTrackerService` 分配（Redis 原子自增 + DB 唯一键兜底）。
- 前端断线重连带 `lastSeq`，服务端从 `seq > lastSeq` 补发。

### 5.3 敏感数据

| 数据 | 存储 |
|---|---|
| 用户密码 | BCrypt |
| 子 Agent 内部令牌/委托密钥 | 环境变量/密钥，DB 只存 `credential_ref` |
| 子 Agent 确认令牌 | Redis，TTL 10 分钟，不落库 |
| 审计请求/响应 | 脱敏后摘要，禁止存完整令牌/密码 |
| 附件 | MinIO 私有 bucket，下载走鉴权/预签名 |

### 5.4 多租户预留

- 所有业务表保留 `tenant_id`；
- 首期统一 `'0'`；
- 物业子 Agent 当前固定 `tenantId=0`，多租户前需子 Agent 改造；
- 索引已包含 `tenant_id` 的，后续可直接加过滤条件。

## 8. 建库与隔离

```sql
-- 待用户确认后执行；不得使用 root 运行应用
CREATE DATABASE IF NOT EXISTS wuye_agent_db
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;

CREATE USER IF NOT EXISTS 'wuye_agent_app'@'%' IDENTIFIED BY '<strong-password>';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX, DROP
  ON wuye_agent_db.* TO 'wuye_agent_app'@'%';
FLUSH PRIVILEGES;
```

> 仅授予本库权限；禁止全局权限；禁止跨库操作。Redis 使用前缀 `wuye_agent:`；MinIO 使用独立 bucket `wuye-agent`。
