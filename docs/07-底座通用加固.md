# 07 底座通用加固

> 版本：v0.1 / 2026-11-24
> 范围：H1 Agent 注册持久化、H2 Manifest 表单聚合、H3 Agent Card 权限声明。
> 边界：只做通用能力，不包含任何具体业务 Agent 的字段、枚举、规则或文案。

---

## 0. 背景

底座支持运行时安装外部 Agent，但动态注册是内存态，重启丢失；个人中心只渲染物业 Agent 的
`forms.personalInfo`；外部 Agent 的能力默认仅管理员可用。这三项是任何外部 Agent 都会遇到的
通用问题，因此作为底座通用加固处理，完成后重新冻结。

设计依据与完整验收见 `flow-agent` 项目的 `docs/08-底座通用加固方案.md`。

## 2. H1 · Agent 注册持久化

### 2.1 表

`apps/java-bff/src/main/resources/db/migration/V11__agent_registry.sql`

关键列：

- `agent_key`（唯一）、`kind`（HTTP/TEMPLATE）、`template_key`
- `descriptor_json`、`base_url`、`internal_token_cipher`
- `audience/actor_id/roles/tenant_id/use_delegation`
- `health_path/ready_path/manifest_path`
- `status`（ACTIVE/REMOVED）、`installed_by`、`installed_at`、`updated_at`

### 2.2 代码

```
agent/install/
  AgentRegistryEntry.java           # 持久化记录
  AgentRegistryStore.java           # 存储接口
  InMemoryAgentRegistryStore.java   # 默认/测试
  MySqlAgentRegistryStore.java      # mysql profile；AES-GCM 加密令牌
  AgentRegistryBootstrap.java       # ApplicationReadyEvent 启动加载
  AgentInstallService.java          # 安装写库、卸载标记、失败回滚
```

### 2.3 行为

- 安装成功后写注册表；写库失败回滚内存注册，返回错误，避免“内存有、库里没有”。
- 卸载时先注销内存，再标记注册表 `REMOVED`；标记失败记录错误。
- 启动时加载 `ACTIVE` 记录：
  - HTTP Agent：反序列化描述、解密令牌、重建 `DynamicHttpAgentAdapter`、注册；
  - 模板 Agent：按 `template_key` 重新注册；
  - 单条损坏/解密失败：跳过并告警，不阻塞其他 Agent；
  - 不主动探活，避免子 Agent 不可达拖慢启动；健康由管理端按需查询。
- 开关：`wuye.agent.registry.load-on-startup`（默认 true）。

### 2.4 测试

- `AgentInstallServiceTest`：安装写注册表、卸载标记 REMOVED。
- `AgentRegistryBootstrapTest`：从注册表恢复 HTTP Agent；关闭开关时不恢复。
- 全量 Java 测试：68/68 通过（2026-11-24）。

### 2.5 未验证 / 待办

- MySQL 真实迁移与重启恢复尚未在共享库执行；计划在 H4 回归前用 `wuye_agent_db` 验证。
- 安装审批/完整审计（G-07）不在 H1 范围。

## 3. H2 · Manifest 表单聚合（待实现）

目标：

- 通用 `AgentManifestService` 聚合已注册 HTTP Agent 的 `forms.personalInfo`。
- 新增 `/api/v1/profile/forms` 与 `/api/v1/profile/forms/{agentKey}`；旧接口保留。
- 个人中心按 Agent 分段渲染；不可达 Agent 降级，不影响其他段。
- Manifest 声明 `getCapability` / `updateCapability`；未声明时物业回退旧能力。

验收：

- 物业表单行为不变；
- 新 Agent 段出现并可提交；
- 不可达降级；
- 旧接口回归通过。

## 4. H3 · Agent Card 权限声明（待实现）

目标：

- Card 增加 `permissions`：`agentUse` + 每个 capability 的角色列表。
- 安装时写 `wa_permission` / `wa_role_permission`，来源 `AGENT:<agentKey>`。
- 卸载时只撤销该来源的权限，不影响内置权限。
- 未声明时保持“仅 ADMIN”的向后兼容。

验收：

- 非管理员可按声明使用外部 Agent；
- 卸载后权限不残留；
- 内置权限不受影响。
